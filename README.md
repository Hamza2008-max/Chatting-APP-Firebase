# 🚀 NovaChat

### Connect. Converse. Create Connections.

**NovaChat** is a real-time chatting application built to make communication simple, fast, and seamless. Powered by **Firebase**, NovaChat brings people together through a modern messaging experience.

Whether you're catching up with friends or starting a new conversation, NovaChat keeps you connected.

---

## ✨ Features

- 💬 **Real-Time Messaging** – Send and receive messages instantly.
- 🔥 **Firebase Integration** – Backend powered by Firebase.
- 🔐 **Authentication** – Secure user login and signup.
- ⚡ **Live Updates** – Stay synchronized with real-time data.
- 🎨 **Modern UI** – A clean and user-friendly interface.
- 🌐 **Cloud-Based** – Access your conversations through an internet connection.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the Project

Navigate to the project directory and open it in your preferred code editor.

### 3. Configure Firebase

- Create a Firebase project.
- Enable Firebase Authentication.
- Set up Cloud Firestore.
- Add your Firebase configuration to the project.

### 4. Run the Application

Open the project using VS Code and launch it with Live Server (or your preferred local development server).

---

## 🔒 Security

NovaChat uses Firebase services for authentication and data storage.

**Important:** Never expose private service account credentials or Firebase Admin SDK keys in your frontend code. Configure appropriate Firestore Security Rules to protect user data.

---

## 🎯 Project Goal

The goal of NovaChat is to explore modern web development, Firebase integration, user authentication, and real-time communication through a practical application.
